# This project presents a classification solution using the Iris dataset and the k-nearest neighbors (KNN) algorithm, implemented with Python and scikit-learn. The code demonstrates key steps of a typical machine learning workflow: data loading and preparation, train-test splitting, model training, evaluation, and prediction. The model achieves high accuracy in classifying iris species based on sepal and petal measurements, as confirmed by metrics such as confusion matrix, precision, recall, and F1-score. This repository serves as a practical example for beginners and enthusiasts looking to understand supervised learning, model evaluation, and scikit-learn’s API for KNN classifiers.
